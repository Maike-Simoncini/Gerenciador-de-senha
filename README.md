## 📱 Sobre o Projeto

Este projeto consiste em um sistema limpo, moderno e responsivo voltado para o **gerenciamento e controle de senhas de atendimento para filas**. Desenvolvido com foco na praticidade operacional, ele permite o gerenciamento rápido dos chamados diretamente por comandos do teclado.

## 🕹️ Modo de Utilização

O controle do painel de senhas é feito de forma intuitiva utilizando o teclado do operador:

- **⌨️ Seta para Cima (↑):** Chama e avança para o próximo número de senha.
- **⌨️ Seta para Baixo (↓):** Retorna para o número de senha anterior.

---

## 🚀 Tecnologias

A aplicação foi construída de forma nativa e leve utilizando as tecnologias web fundamentais:

- **HTML5:** Estruturação semântica da tela do painel.
- **CSS3:** Design moderno, centralizado e otimizado para exibição em monitores ou televisores de atendimento.
- **JavaScript (Vanilla):** Lógica de manipulação de eventos do teclado e atualização de estado em tempo real.
